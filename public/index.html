FAQ

Questions, answered.

What file limits are used?

Documents/images are limited to 50 MB and videos to 1 GB.

Are uploaded files kept?

The local server periodically deletes temporary files after the configured cleanup window.

Does it work on mobile?

Yes. The interface is responsive and can run from Termux.

Does the downloader support private or DRM content?

No. It is designed for public, non-DRM media only.
